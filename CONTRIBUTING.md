# Contributing to the public documentation projection

This is a reviewed, sanitized publication of the private maintenance knowledge base, not a second independently maintained source. Propose corrections without attaching private originals; maintainers apply changes to the maintenance source and review a new public projection. No automatic recursive copying of referenced documents or attachments.

Read the unmodified DCO 1.1（内部记录未公开） and sign your own new commits with `git commit -s` only if you can make that certification. Public identity/email and the contribution are retained in public history. DCO certifies rights, not copyright transfer; AI-assisted text still requires a human source, license, privacy and factual review. Do not forge historical sign-offs.

Prose is CC BY 4.0 as described in LICENSE; preserve attribution and identify adaptations. Code examples retain their explicitly applicable licenses. This license does not relicense Numen code, APIs, assets or third-party material. Do not submit credentials, model configurations, private conversations, raw logs, local paths, private evidence, game saves, copied proprietary content or unreviewed attachments. Keep incomplete/unknown status intact and do not turn a design into a verified claim.

Validate relative links and source assertions, provide the reason and affected pages, and state the verification boundary. A lack of scanner matches is not proof of safety. This policy adds no mandatory CI gate, branch-protection rule, copyright assignment or CLA.
