# AC：会计算和选择的动作组合

> 公开改写摘要；来源主题：ACX。既有Runner/目录/版本与部分并行候选可复用，完整异步抢占恢复等不据本文宣称已完成。

目标链是：取当前世界参数 → 公共计算/筛选 → 条件选择 → 参数绑定 → 原子动作或子 AC → 真实结果 → 必要时重观测。变量、分支、有界循环和结果绑定是能力，不只顺序播放固定工具表。

复用原 Loader/Runner、版本库、实际注册工具和身体宿主。常驻基础、情境浮现、长尾检索、按登记条件自动触发是四种使用方式，同一身份与版本不复制；目录出现不等于自动执行。任务型条件由任务宿主登记、去重和撤销，ACX拥有定义和运行。

多个 run 可同时观察、计算和等待；争同一身体资源时由原宿主唯一裁决。普通冲突明确等待，不静默取消旧动作；确需抢占时保断点及已确认副作用，危险解除后重读位置、目标、装备、补给和任务条件，再续跑或退出。空槽不等于原路径仍有效。

子 AC 与临时组合固定依赖版、有类型输入输出、父子归属、取消传播、深度与总预算；父等待不能冒进展，迟到回执不串新 run，副作用未知时不盲重发。新版本服务新运行，在飞版本迁移另核兼容。

工具按阶段自查有效进展并有限自救：有效路径推进、真实破块、匹配掉落和实际入包分别核。来回跑不算采矿产出；正常原地挖、绕障、合法等待不误伤。预算不因子调用重置，耗尽应释放资源、交上层，不由采矿工具自行启动睡眠。

验收不仅看静态可执行，还核实际工具可见、调用归属、取消恢复、真实世界产出及扫描/计算成本。旧高层工具逐项证明替代后才隐藏，保实现和回退。

代码入口：[ACX plugin](https://github.com/nuomi2422/minecraft-numen/tree/main/plugins/acx)、[Numen API](https://github.com/nuomi2422/minecraft-numen/tree/main/api)。
