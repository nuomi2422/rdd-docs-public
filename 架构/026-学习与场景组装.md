# 学习、独立组件与场景 skills

> 公开改写摘要；来源主题：学习线。部分目录/正文交付已有历史记录，不等于自然采用和效果闭环已完成。

外置学习者当前主力，主动观察实验或接内部信号，结合真实输入、选择理由、调用/返回和世界后态归因。先查重，再复用或修订；不是每个问题都新造技能，程序缺陷应修程序，观测不足补观测。内部未来在受限模板与同框架中组合，不作当前前置。

经验、AC、主/支/日常模板、环境专题和设施方法能单独登记、检索、展开及使用，也可被场景 skill 按版本引用。包不复制正文，不取得世界、任务或身体写权。必需依赖缺失明确不可执行，可选缺失可降级；独立与包内同时命中要去重，退出只释放自己的引用。

召回由最终/当前目标、任务性质、世界场景、风险、资产和能力共同提供线索，不要求预知名字。先目录的用途、原因、条件、版本，再按需取单件或整包。规划偏路线与依赖，执行偏当前步骤与环境；知识相似用于找方法，实际结果必须按精确任务/调用归属。

内容的候选/试用/发布/撤回，与AC运行、逻辑任务、世界缓存、专题挂载是不同生命周期。共同关联来源、版本、条件、轨迹和多面效果，不强并一个大状态机。撤内容不回滚已发生动作，撤包不误卸他人引用。

合法产物经机器检查进入适用试用，采用或拒绝、后态、成本及副作用再反馈。检索命中、正文送达、实际采用、动作成功、业务有效分别取证。缺原证保持未判，错误版本退出活跃目录但保历史；误判可以修评价，不能随意删正确能力。

实验工具只读取游戏AI的输入/行为/后态等证据，不是新的身体控制者。索引已旧和窗口无匹配分开，外部观测调用不算同伴动作。
