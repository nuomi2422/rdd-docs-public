# 统一世界数据：获取、计算、存储、读取

> 公开改写摘要；来源主题：WorldState。设计已明确，有部分实现；完整接线和效果未整体验证。

共同链路：游戏采集器、领域事件和投影 → 按身份增量获取 → 原始观测 → 公共有界计算 → 派生存储/缓存及失效 → 精确读取与检索条件 → AC、任务、环境、规划/执行和学习消费。

原始值保来源、世界/主体、时刻、范围和覆盖；派生值注明输入修订、算法版本和参数。缺测不是零，未加载不是消失；历史快照不能贴新时间冒当前事实。输入、算法、范围、世界/身体身份改变，或结果到期后应失效或重算；旧刷新迟到不能覆盖新结果。

算术、比较、范围过滤、聚合和排序应复用，明确类型、单位、缺值和成本，不让每个 AC 各扫全世界。精确读回答“现在是什么”，语义检索回答“有什么方法/相关对象”，两者共享条件与来源而不混用。读取不暗中扩成全图扫描，必要刷新有界执行。

观测归 WorldState，设施归 Settlement，任务与资产归其领域宿主；公共投影不取得写权。环境块组织当前信息，长期地图/资产记录有用途的历史和可用性。实际动作前仍保本地安全复核。

验收覆盖：过期/错身份、未知与确零、新旧结果乱序、断流重建、计算成本，以及规划/执行/AC真实读到同一输入。后台有值或单测通过不等于最终请求已消费。

代码入口：[world-state-core](https://github.com/nuomi2422/minecraft-numen/tree/main/world-state-core)、[worldstate plugin](https://github.com/nuomi2422/minecraft-numen/tree/main/plugins/worldstate)。这些是可变分支定位，不是某次运行的固定版本证据。
