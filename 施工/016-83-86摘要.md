# 83/85/86/80 摘要（学习线闭环/实验坑/契约/投递钩子）

## 83 最小闭环交接

自然事件→memo→完整轨迹→复盘→经验→投送正文，五段真机跑通。第六段（行为差异）做了三对 A/B（0v1、1v1、2v0），方向一致、幅度小、样本小：pilot 支持，不是统计结论。最值钱的发现：zero-start 只清背包不清上下文（最近 ≤200 条消息回放进请求，与剥掉工作台的母版打架）。现在缺的不是干净母版，是“不会被工具回执抢先教会”的场景（craft 失败回执自带做法，两组 3–4 秒照做）。

## 85 实验失败坑与写法

失败实验不是废数据，是下一次设计输入；必须写清“哪一步无效”，不能把 INCONCLUSIVE 写成 PASS，也不能把“有改善”写成“学会”。三层写法（实验卡/杂项/周报）别混。

## 86 学习线契约 v1（用户已批准，最高真源）

意图：让 agent 通过经验积累变强，以采用及行为差异检验，不以写入量证明。学习者写记忆/经验/ACX 草稿/携带器草稿/自编译工单；防御规则是自动规则草案，不挤掉携带器。人审证据契约，机器依约验证发布；不可逆对外仍须签字。数据流：世界事件→采集器→学习者→质量门（三态）→发布门→检索层（唯一入口）→三视图→执行/规划 AI→投送与运行证据→采集器。
