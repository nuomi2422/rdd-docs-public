## 历史设计（2026-11-08，仅追溯；新增字段方案暂不采用）

## 一、先分清两个东西

- **状态（state）**：节点此刻发生了什么 —— 当时用PENDING / PARTIAL / DONE / FAILED / SKIPPED / DEFERRED作概念例子，**不是当前源码枚举**。状态会变，且**不是性质**。
- **稳定声明与动态评估分离（候选）**：节点意图、行为类别、证据契约及依赖声明可版本化；风险等级、准备是否满足与可达性则是随环境变化的评估快照，携带来源、观察时间、有效期/失效条件及版本。环境变化可触发重新评估，不要求改写节点意图。

| `verify` 验证 | INVENTORY / BLOCK_STATE / ENTITY / OBSERVATION / SCRIPT | 完成证据来源；允许多种世界事实组合，组合语义及UNKNOWN传播需明确 |
| `deps` 依赖 | 节点/资产引用及关系类型（候选） | 区分硬依赖、软建议与替代关系；是否采用DAG及兼容现有实现仍待验证，不将全部依赖当硬前置 |
| `reuse` 复用 | ALWAYS_RECHECK / SKIP_IF_VALID | 已有设施按现实有效性核对再决定是否重建（对应「不重复建造」） |
| `tags` 自由标签 | 任意字符串 | 不参与枚举判定，只做检索/审计 |

### 动态待办关系（D-20261108-013，候选）

主线/支线/日常是逻辑待办与主次指针，不等同多身体并行。挂起、取消、延后提醒是生命周期动作；风险、事实与可达性随环境及证据时效重评估。与稳定性质声明分开，复用已有状态机，具体状态迁移和兼容方案待查证设计，不预设已实现。

## 四、组合与未知值

- **多标签**：枚举维度各自单值（避免组合爆炸），跨维度组合自由（如 TRAVEL+HIGH+HARD）；自由描述进 `tags`。
- **未知值**：每个维度都允许 `UNKNOWN`，但**必须带 reason**；`UNKNOWN` 不默认通过或失败；安全关键前提应补证据或选安全替代，非关键字段可降级，规则需按场景和现有契约设计，不一概放行。
- **历史版本化候选（本批不采用）**：曾建议节点里加 `traitsVersion`；新维度只增不改语义；旧节点没有 traits → 按 UNKNOWN 处理并记一条迁移待办，不强行回填。

## 五、例子

- 下界探索：`kind=TRAVEL, risk=HIGH, prep=HARD(门材/护甲/退路), verify=OBSERVATION, deps=[进入下界]`；示意值不代表固定准备清单或自动插入策略已确定。
- 建农田：`kind=BUILD, risk=LOW, prep=NONE, verify=BLOCK_STATE, reuse=SKIP_IF_VALID`。
- 交易准备：`kind=PREP, risk=MEDIUM, prep=NONE, verify=ENTITY(村民+交易位), deps=[找到村庄]`。

## 六、不做什么

- 不规定每阶段必须有哪些节点（那是主人的经验，不写死）；
- 不把 `prep` 的具体物品清单硬编码进枚举；
- 当时未实现的新字段仍不采纳；当前最小复用和消费者包已在前节定稿。安全需求与支线实现分开，拒绝不是失败，吃饭不虚构为支线；环境变化后的重评估及正反例沿044 §0.2执行（D-20261108-012）。
## 七、实况审计示例（2026-11-08，只读，不下结论）

当前 fresh-auto 规划审计口头报告显示：可见下界门→堡垒→末地→要塞→终局；未见独立基地/交易 primary，干草只在可选二级措辞中，末批可能直接 COMPLETED。**这些只能作为本次规划/时间范围内的观察，不能把「未出现节点」当成「没做过」**；需等主干活补源码行、快照时间窗、事件时间范围。

该历史口头样本提示四类待解释语义，不构成必须新增四个字段的证据：
- `deps`：准备依赖（例如进入下界前的准备节点）；
- `reuse` + `verify`：已有资产核验与现实有效性，不重复建造；
- `prep`：软约束/硬约束（缺硬准备不得开始）；
- `state` + `evidenceWindow`：节点状态和真实世界证据时间窗分开，不能用「没在本次窗口出现」代替未完成。

续批也不是性质：它是 TaskChain 生命周期行为，应单独验「末节点 COMPLETED 时是否允许生成下一批」的代码/运行证据。

### 重评估与反例（候选，未实现）

- 正例：地下白天无可达床时主动DECLINED并恢复；后来地表夜间出现危险或床可达性变化，以新观测触发安全需求重评估，可重新激活合理行动；拒绝本身不等于失败，也不保证一定再触发睡觉。
- 反例：环境未变且无新增危险，不因一次旧拒绝无限重复提醒；冷却不能屏蔽已证实的重大风险变化。未加载/信息过期/跨世界身份不明则标UNKNOWN，不假定安全或危险。
- 把同伴、世界会话、阶段/支线实例、评估前后观察与实际动作终态关联；逐项核验，回放结果不冒充当前世界事实。
