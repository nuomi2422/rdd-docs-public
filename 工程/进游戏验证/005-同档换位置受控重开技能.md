# 005 · 同档换位置受控重开技能

**仅外部驾驶 AI 在主人已授权的同一存档、同一同伴上使用；不交给游戏 AI 自行清空。** 版本1，2026-11-11。原因：污染旧开局不能检验自主线路，但新建世界会丢连续证据；本技能复用现 MCP（模型上下文协议）命令与任务入口，不另造 runner。

## 检索、调用与撤回

检索名：同档重开／换位置重开／受控重开；技能ID：skill.external-controlled-restart。外部驾驶者读取本正文，逐步调用已有 server_command、reset_companion_world、task_status/task_stop、settlement_list/unregister、get_self_status、rdd_respawn_info 与正常目标入口。**这不是一键自动执行工具。2026-11-11 已由 DSH 标准文件系统技能发现并实际载入验证：目录名 `rdd-controlled-restart`，provider=`filesystem`；加载仅返回要求读取本正文的薄入口，不触发重开。** 入口文件位于 `[本机路径已省略]`，唯一流程仍是本文，不复制第二份。知识库入口也可检索；撤回时把本文 status 改为 withdrawn 并移除上述技能入口及知识库调用指针，保历史证据，不卸载安全消费者。

## 前置条件（任何一项未知就不清空）

- 唯一驾驶员、原实例原存档、目标 UUID 与实际 owner 已核。拿当前 world_id/server_session，重入后旧 session 失效必须重取。MCP token 必须非空、HTTP 鉴权有效；不读取或输出 token。
- **2026-11-11 22:20边界修订**：按卡003主人纠正，只用原实例原live，不新建测试实例、不复制世界；两处历史世界备份已删除，旧路径不能当当前回滚保证。重开前先正常保存并记录目标同伴的资产、任务、HOME/床、背包/playerdata等定向状态与必要恢复信息，保历史证据；不把此项扩成重建整份世界副本。`backup_receipt`只是操作者声明：实际没有整世界备份时不得声称有，先核现接口是否允许如实表达当前恢复范围，无法满足契约就报告具体差距，不填虚假回执。原因：此前把复制存档误作既有授权造成返工，本条取代旧“必须有整世界副本”前置。
- 记录原模式、效果、坐标、生命与饥饿；保经验、why、技能、AC动作脚本、模型配置与历史。核旧身体任务和输入已通过现 owner stop 生效，不以 accepted 代替实际停止。
- 只用主人授权的精确命令；实体选择器限该 UUID 或 @s。server_command 是管理员原生命令接口，**不是作用域沙箱**：owner 绑定不能阻止 @a/execute 影响其他实体，禁止使用广泛选择器、改世界出生点或任意删目录。

## 步骤（一次 reset，失败后查状态不重复清空）

1. 列目标 task_status 的 timers；逐个 task_stop(task_id=tm...) 取消，仅核该同伴，复查为空。列设施并核原 ownerId：本人旧登记先备记录后逐条 settlement_unregister；该登记保护会解除，物理建筑不破坏；他人/共享设施不全局注销。当前无安全定向解绑口时停在这里并报告，不造“干净”结果。
2. 调 reset_companion_world，传 confirm=true、精确 companion/world_id/server_session、真实备份引用。核回执及独立后态：主链空、世界资产/旧 HOME 与床偏好已清、全41格（含装备和副手）空。失败或受理不明先读后态，不重发；部分清理不是完成。经验/技能/模型/历史不在清理范围。
3. 给临时原生保护 120 秒，例如 resistance amplifier=4；核实际有效及剩余游戏 tick。首次版本已有受控 fall 类型伤害4点前后生命不降及真实高空落地不降证据。**不得靠两分钟前墙钟回执保证当前保护**；未知就不跳高空，必要重施本次临时保护并标介入。
4. 远处目标约万格外。先查/确认可站陆地，不盲连续海上投放。可复用原版 spreadplayers 的安全地面搜索，限定远处区域且仅 @s，再用 get_self_status 实核地面、非水/熔岩、空气与生命。该动作是受控选点，不算自然探索。随后保护有效时在已确认同坐标 y≈300 投放，核真实落地、生命、非液体。
5. 若落海或气不足，立刻用现 API 救回最近已确认安全地面，标 fallback，**不能算重开成功**；不要为了菜单调查留在水里。查地形后继续同轮，不重新 reset。
6. 在实际站立安全地面为仅该同伴设 spawnpoint（不是300高空）。用 rdd_respawn_info 核维度/地面坐标，原生 forced 点可用，之后正常睡床允许更新。新消费者只有真实死亡重生才消费个人点；活体休眠载入必须保原位。
7. 设晴天、刚日出。保护自然到期或按原状态解除，独立核无临时效果且模式恢复；effect clear 报“没有该效果”须看后态，不自动视为失败。天气/时间命令返回码可以为0或负数，不凭正负签业务效果。解除后再校准时间/天气。
8. 派本次人类明确授权的准确总目标，不给物、不代做逐步工具；未另指定时沿原“通关MC”，人类已明确主世界安身立命等范围时以该原文为准，不擅自扩成末地终点。本次目标唯一见174工程（内部记录未公开），正式目标按该工程§4仅替换历史地点前缀为确认安全新点/新落地点附近，记录旧→新绑定及实际发送全文，其余意图与边界原样，不能仍发旧坐标诱导返程。若前面上过 owner stop 闩，先确认新目标已绑定，再沿正常 `/stop resume` 仅一次解除；必须核实际 latch cleared 及随后首条执行模型请求/工具，supervisor 规划成功不等于身体已恢复。保存新目标实际规划、同一会话的动作与后态；受控清理、投放、验证死亡属于 INTERVENED，后续自然表现分开。

- 本次实际已证：真实命令结果、错 world/session/confirm 拒绝；一次定向 reset 后41格空/链空；目标自有2设施注销/他人2设施保持；保护落地不损血；个人地面一次受控死亡回新点；活体在远离个人点的位置保存重入保持精确原位。
