## 自动判读（2026-11-05 新增）

跑完一次运行后，直接执行：

```
powershell -NoProfile -File scripts/verify-pending.ps1            # 默认看最近 120 分钟（UTC）
powershell -NoProfile -File scripts/verify-pending.ps1 -Since 2026-11-05T05:00
```

输出三行：A1 world_state 同伴调用数、A2 learner_note 同伴调用数、A4 condition verdict 分布。

- 0 次 → `NOT OBSERVED`（不是失败，是没触发）；
- verdict 仍全是 MATCHED → `STILL ALL MATCHED`（判别力不够）。

> 注意：日志时间戳是 **UTC**，脚本的默认窗口也按 UTC 算。用手写本地时间去比会得到「全是 0」——
