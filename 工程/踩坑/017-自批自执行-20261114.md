# 规则：自批自执行，事后给主人看台账（2026-11-14 主人定）

## 规则

1. **除“收工”外，一切请求自批自执行**：不必向主人请示、不必等确认、不必解释过程。
2. **唯一保留给主人的决定**：收工/停工（只有主人能叫停）。
3. **必做台账**：每次自批写一行到 `知识库/自批台账-20261114.md`——时间 / 批准了什么 / 依据 / 影响范围 / 结果。**主人只看台账，不看请示。**
4. **仍不可做（无需请示，直接禁止）**：不可逆/破坏性（删大量数据、清存档、清历史）、可能搞坏机器、对外不可撤回。
5. **代价可见**：主人自付云机与 token 成本（内部记录未公开）。活着但不出活 = 直接烧钱，按 015 记违纪。

## 为什么（设计的缺口）

主人常态不在，逐次审批＝必然停摆＝烧钱。**审批链条本身就是最大的成本源。** 所以：**默认自批、只留收工权、用台账替代请示。**
