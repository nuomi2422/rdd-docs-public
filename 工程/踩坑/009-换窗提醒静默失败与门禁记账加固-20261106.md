# 009 · 换窗提醒静默失败 + 门禁记账加固（2026-11-06）

> 两件都是「看起来在守、其实没守」的同一族：与 008《门禁记账被绕过》互补，
> 008 讲入口被绕过，本篇讲**执行本身静默失败**和**自检不记账**。

## 现象

- 全局探针 `~/.dsh/dsh-smart-compact/engine-state.json`：引擎 mounted=true、auto=true、
  今天自动换窗 4 次（pressure 触发），但 `reminderObserved.passFailures=3`，
  `lastPassFailure = "cannot resolve the routed model for session … (no agent options and no request header)"`。
  即换窗在跑，但**分级提醒 / grace 提醒在部分会话上整轮没触达**，且没人知道。
- 本会话 `ctx_history list` 仍是 `live window #1`（没换过窗），说明全局 rolloverCount 是
  **别的会话**贡献的，单个会话的「有没有换过」要按会话自己查。
- 门禁账本 `[内部日志未公开]` 里 `selftest` 从没记过；`verdict()` 的 `appendFileSync`
  被 `try{}catch{}` 静默吞掉，写失败（权限/磁盘/路径）不会报；24 条 `gate=unknown`
  是旧版 `__GATE_MODE` 未设时写入的。

## 根因

1. **换窗提醒**：`reminder.js` 从 `system-prompt/assemble` 拿到 `context.agent`，
   却只把 `agent.session` 传给 `getBudget`；`index.js` 的 `getBudget` 再造一个
   `{ session }` 假 agent。`budget.js` 的 `resolveModelTarget` 需要
   `agent.options.provider/model` 或 `session.requestHeader().config` 才能查
   contextWindow —— 两者都缺就抛错，`reminder.js` 的 catch 只记 `pass-failed`
   并继续返回未改的 prompt，**提醒静默消失**。
2. **门禁记账**：`verdict()` 用 `try{}catch{}` 包住 appendFileSync 但 catch 体为空；
   `selftest` 走 `runSelftest()` 直接 return，不经过 `verdict()`，所以不记账。

## 修法（2026-11-06 已做）

- 插件运行时补丁（已装副本 + `.tmp/sc/package/lib` 源码副本同步改，node --check 通过）：
  - `reminder.js`：把整个 `context.agent`（含 options / requestHeader）传给 `getBudget`；
    老宿主无 agent 时退回 `{ session }`。
  - `index.js`：`getBudget` 接收 agentOrSession，有 `.session` 就当真 agent 用，否则兜底包装。
  - **升级 dsh 或重装 dsh-smart-compact 后必须重打**（node_modules 会被覆盖）；
    原文件备份在 `[内部路径已省略]`。
  - 需重启 / 重载 DSH 才生效；生效判据：`engine-state.json` 的 `passFailures` 不再增长、
    `reminderObserved.tiers/grace` 按会话正常累计。
- `bin\harness-gate.js`：抽 `appendGateUsage()`，写失败**显式打 stderr 警告**（不再静默吞）；
  `verdict()` 改用它，note 带完整 SKIP/ASK 计数；`selftest` 结束记一条
  `gate=selftest`。实测三模式各 +1（104→107），`selftest PASS` 首次进账。
- `bin\gate-usage.js`：用法补 selftest、报表加「门禁自身健康自检」行、给
  `unknown` 读时归一化加注释（历史数据不回写，留证）。
- `~/.dsh\AGENTS.md §3`：指针从「skill 名 dsh-smart-compact」（本会话 catalog 里
  没有这个 skill）改成真实手册路径 + engine-state 探针路径 + 升级重打提醒。

## 怎么一眼看出没生效

1. `cat ~/.dsh/dsh-smart-compact/engine-state.json` 看 `passFailures` 和
   `reminderObserved`（briefed / tiers / grace / noBudgetSessions）。
2. `node [内部路径已省略] status` 看四道门
   （code / preflight / postflight / selftest）的最后时间与 HEALTHY。
3. 账本 `[内部日志未公开]` 里若出现新的 `gate=unknown` 或 stderr 出现
   「⚠ gate-usage 记账失败」，就是又退化了。

## 边界

- 只修了「提醒解析不到模型」这条静默失败；**换窗引擎本身一直是好的**
  （rolloverCount 4 次、budgetDegraded=false）。别把「提醒没触达」误报成「换窗没跑」。
- `UNHEALTHY` 是账本最后一次结果是 BLOCK 的老账（P0/P14/P9/Q17/Q20），
  不是门禁失灵；`gateStatus` 按最后一次结果判定，符合设计。
- `thresholdRatio` 在 profile 里被设成 0.55（README 默认 0.85），是 2026-11-02
  主人有意下调，未改。
