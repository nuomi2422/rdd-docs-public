# 游戏内能力回归清单

> 目的：定期确认“游戏里原本会做的事”没有退化。**每次核对必须写时间、runId/证据路径**；没核对就写 UNKNOWN，不写“正常”。

## 检查协议

- 触发：改动影响某能力或现场出现退化时核相关条目，不每次发布或固定每周重跑全表。
- 执行：当前驾驶员按本次场景核相关能力，记录世界后态；没触发的记未覆盖，不主动凑无关实验。
- 记录：更新本表“最近核对/结果/证据”三列；失败写 FAIL 并开救债条目。

## 按需诊断线索（不是门禁）

> 仅在怀疑失效时使用；调用次数、日志大小和启动回执不能自证世界效果。
> 起因：2026-11-05 同一晚出现两次「东西做出来了但没接上」——刷新信号没接线、`world_state` 没进白名单。

| 编号 | 何时跑 | 命令 | 通过标准 |
|---|---|---|---|
| G-01 | 怀疑工具未送达 | `powershell -File scripts/tool-whitelist-check.ps1` | 输出里新工具不在 `NOT IN ANY WHITELIST` |
| G-02 | 怀疑未采用 | `powershell -File scripts/companion-calls.ps1 -Tool <名字>` | >0（0 次要解释：没人用 / 白名单 / 调用条件不成立） |
| G-03 | 部署异常 | `scripts/preflight-deploy.ps1` | PREFLIGHT: ALL OK |
| G-04 | 启动异常 | 启动脚本输出 | 出现 `LAUNCH_OK`；若出现 `LAUNCH_NOT_STARTED` 先看 `batErr` |
| G-05 | 日志占用异常 | `scripts/monitor-report.ps1`（已合并轮转归档） | monitor 目录 < 1 GB；占比最高的 type 有解释 |
| G-06 | 改动工具可见性/白名单后 | `powershell -File scripts/tool-request-check.ps1` | 最后一条请求里 tools 数 = 白名单 ∪ RESIDENT；`whitelisted-but-missing` 必须为 0 |
